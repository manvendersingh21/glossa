# SFMTA public-records request template

Copy, narrow, and edit this template before sending it through San Francisco's
official public-records channel. A smaller intersection list and date range will
usually make the request easier to search and fulfill.

The [San Francisco City Attorney's Sunshine guidance](https://www.sfcityattorney.org/good-government/sunshine/)
explains that requests may be made orally but that writing can avoid confusion.
This project template is practical drafting help, not legal advice.

---

**Subject:** Public records request — traffic-signal timing plans and metadata

Hello,

Under the California Public Records Act, I request electronic copies of existing
traffic-signal timing records for the intersections listed below, for records in
effect at any point from **[START DATE]** through **[END DATE]**:

**[LIST INTERSECTION NAMES, CNNs, AND/OR SFMTA SIGNAL NUMBERS]**

For each intersection and time-of-day/day-of-week plan, please provide any
existing records that identify:

1. plan or pattern identifier, effective dates, days and time windows;
2. cycle length, phase sequence, phase splits or programmed intervals;
3. coordination offset and reference point, where applicable;
4. pedestrian timing parameters and recall/actuation settings;
5. transit priority, emergency preemption, adaptive operation, or free-operation
   indicators that affect whether a fixed plan runs; and
6. the controller/location identifier and any field needed to join the record to
   SFMTA's published Traffic Signals inventory.

Timing sheets/cards, controller database reports, Synchro or similar exports,
spreadsheets, CSV files, and machine-readable plan reports are all acceptable.
I prefer the records in their existing electronic format with field definitions,
rather than scanned printouts. Please include a data dictionary or report layout
if one already exists. I am not requesting passwords, network addresses,
cryptographic material, or real-time access to control systems.

If the full request is burdensome, please contact me before narrowing it. I would
be glad to prioritize **[INTERSECTIONS OR RECORD TYPES]**. If responsive fields
must be withheld, please provide the reasonably segregable remainder and identify
the legal basis for each withholding. If records are held by another City unit,
please advise where the request should be directed.

Please notify me in advance if estimated duplication or extraction fees will
exceed **[$ AMOUNT]**. Electronic delivery to **[EMAIL OR DOWNLOAD METHOD]** is
preferred.

Thank you,

**[NAME]**  
**[CONTACT INFORMATION]**

---

When records arrive, preserve the original files, delivery message, effective
dates, and field documentation. Do not relabel a plan as current merely because
it was delivered recently; its own effective dates determine freshness.
